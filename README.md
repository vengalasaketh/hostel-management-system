\# Hostel Management System



A web-based Hostel Management System developed to simplify hostel administration, student registration, fee management, notices, events, sports information, and other college/hostel-related operations.



\## 🚀 Features



\- Student registration and login

\- Student profile management

\- Hostel admission management

\- Fee management

\- Admin dashboard

\- Admin authentication

\- Notices and announcements

\- College news and events

\- Sports information

\- Gallery

\- Contact and information pages

\- AI-powered functionality using OpenAI API



\## 🛠️ Technologies Used



\- \*\*Frontend:\*\* HTML, CSS, JavaScript

\- \*\*Backend:\*\* PHP

\- \*\*Database:\*\* MySQL

\- \*\*Additional:\*\* Python, OpenAI API

\- \*\*Local Development:\*\* XAMPP

\- \*\*Version Control:\*\* Git \& GitHub
